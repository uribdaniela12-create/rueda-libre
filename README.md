Rueda Libre

Descripción

Rueda Libre es un sitio web de alquiler de bicicletas en Medellín. Permite consultar bicicletas disponibles, conocer las tarifas y realizar reservas.

También incluye Rueda Nocturna, una campaña con recorridos nocturnos, diferentes planes y un formulario de inscripción.

Páginas

- Inicio:información general y promociones.
- Tarifas y rutas:precios y recorridos disponibles.
- Reservas:formulario para reservar bicicletas.
- Rueda Nocturna:rutas nocturnas, planes e inscripción.
- Kit de componentes:botones, alertas y campos reutilizables.

Diseño

Utilicé los colores Verde Ruta, Naranja Pedal, Azul Noche y Crema para mantener la identidad visual de Rueda Libre.

También trabajé con las fuentes Montserrat y Open Sans.

Rueda Nocturna incluye diseño responsive y modo oscuro.

Bootstrap vs. Tailwind

Utilicé Bootstrap para construir el sitio principal y Tailwind CSS para Rueda Nocturna.

Después de compararlos, recomiendo Tailwind para Rueda Nocturna porque permite personalizar fácilmente el diseño y generar un CSS más ligero.

Al minificar el CSS, conseguí una reducción aproximada del 19,12 % en la prueba realizada.

Aprendizajes

Durante el proyecto aprendí a crear páginas responsive, utilizar componentes reutilizables, trabajar con formularios y validaciones, mejorar la accesibilidad y organizar mi código utilizando Git y GitHub.

Estado de los formularios

Los formularios cuentan con validaciones. La inscripción a Rueda Nocturna todavía necesita conectarse a un servicio para guardar los datos de los participantes.
